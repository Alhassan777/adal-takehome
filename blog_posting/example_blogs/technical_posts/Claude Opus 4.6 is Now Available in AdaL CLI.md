# Claude Opus 4.6 is Now Available in AdaL CLI

Claude Opus 4.6, Anthropic's latest model, is now rolling out in AdaL CLI. In early testing, Claude Opus 4.6 excels in agentic coding, with specialization on especially hard tasks requiring planning and tool calling.

## Availability in AdaL CLI

Claude Opus 4.6 is available starting from version `0.6.2`.

You'll be able to select the model via `/model` in:

- Chat, edit, and agentic workflows
- Thinking Mode (extended reasoning enabled by default)

Use `/model` to select Claude Opus 4.6 from the model picker.

## Get Started

```bash
npm install -g @sylphai/adal-cli
adal
```

New users get $5 in credits to try it out!
